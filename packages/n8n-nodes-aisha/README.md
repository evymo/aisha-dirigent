# n8n-nodes-aisha

> AISHA Platform custom n8n community nodes — gateway RPC, MCP, audit, delivery, self-orchestration.

Community [n8n](https://n8n.io) nodes for the AISHA platform: call AISHA gateway
RPCs, integrate the MCP surface, write audit trails, drive delivery flows, and
orchestrate the autonomous self-* loops directly from n8n workflows.

## Install

In n8n: **Settings → Community Nodes → Install** `n8n-nodes-aisha`, or:

```sh
npm install n8n-nodes-aisha
```

Published to the AISHA private registry (Verdaccio).

## Nodes

`aishaRpc` (gateway RPC), MCP integration, audit, delivery, and
self-orchestration nodes. See each node's description in the n8n editor.
