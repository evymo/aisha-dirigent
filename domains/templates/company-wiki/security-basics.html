Security basics everyone should know

Updated last week · 3 min read

You don't need to be a security expert. A handful of habits cover the vast majority of real risk — and they take an afternoon to set up once, then look after themselves.

Use a password manager

Every account should have a long, random password you've never used anywhere else, and the only sane way to do that is a password manager. Let it generate and remember them — you only memorise one strong passphrase for the manager itself. Reusing a password is the single most common way accounts get taken over.

Turn on two-factor

Two-factor authentication means a stolen password alone isn't enough to get in. Switch it on for email, the password manager, and anything that touches customer data — an app-based code or a hardware key, not SMS where you can avoid it. If something ever feels off, change the password and tell us; we would much rather hear a false alarm than miss a real one.

Remember: We will never ask for your password — not over chat, not over email, not on a call. Anyone who does is not us.
