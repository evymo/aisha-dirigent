# Roadmapa AISHA Platform

> Veřejná roadmapa pro období kolem official RC.

## Aktuální stav

Projekt je ve fázi přípravy na official RC: hlavní produktové a infrastrukturní vrstvy existují, probíhá čištění veřejné dokumentace, jazykových verzí a release narrative.

## Co je už hotové nebo ve vysoké připravenosti

- Základní platform stack: web, API gateway, databáze, workflow orchestrace
- Keycloak jako hlavní identitní vrstva a AISHA e-mailové šablony
- MCP knowledge vrstva a expertní pravidla pro AI orchestrace
- Základní observabilita, gate testy a release disciplína
- Branding a průběžný rebrand na AISHA Guru v klíčových částech systému

## Co je cílem official RC

- Ujasnit veřejný dokumentační set a jazykové verze
- Uzavřít nejviditelnější naming a obsahové nekonzistence
- Odstranit z veřejně sledovaných souborů konkrétní tokeny a lokální konfigurace
- Potvrdit, že release narrative odpovídá skutečnému stavu projektu

## Co přijde po RC

- Hlubší agentní observabilita a evaluace kvality odpovědí
- Rozšířený tool system a dynamičtější agentní workflow
- Session a long-term memory vrstva
- Proaktivní agentní triggery a další automatizační smyčky
- Další rozšíření veřejné dokumentace v angličtině

## Praktický princip roadmapy

RC není konec vývoje. Je to bod, kdy je projekt dostatečně srozumitelný, bezpečně prezentovatelný a vnitřně konzistentní, aby mohl být ukázán jako skutečný produkt, ne jen jako interní experiment.
